# Mark Harvest

ウェブページのメインコンテンツを抽出し、Markdownに変換します。

![Mark Harvest Logo](./public/icons/icon128.png)

Mark Harvest は、Mozillaの Readability ライブラリを使用してウェブページから主要なコンテンツを抽出し、Turndown を使用してクリーンな Markdown 形式に変換するシンプルで強力な Chrome 拡張機能です。

## 特徴

- **スマートな抽出**: Firefox のリーダービューでも採用されている `@mozilla/readability` を使用し、広告やナビゲーションを除去してメインコンテンツのみを特定・抽出します。
- **クリーンな Markdown**: `turndown` を使用して、HTML を扱いやすい Markdown 形式へ変換します。
- **かんたんコピー**: ボタンを一回クリックするだけで、抽出された Markdown がクリップボードにコピーされます。
- **開発者に優しい設計**: Vite、TypeScript、Vitest といったモダンな技術スタックで構築されています。

## インストール方法

### 一般ユーザー向け

(下の「開発者向け」セクションを参照。)

### 開発者向け

1.  このリポジトリをクローンします。
2.  依存関係をインストールします。
    ```bash
    pnpm install
    ```
3.  拡張機能をビルドします。
    ```bash
    pnpm build
    ```
4.  Chrome に拡張機能を読み込みます。
    - Chrome を開き、 `chrome://extensions/` へ移動します。
    - 右上の「**デベロッパー モード**」をオンにします。
    - 「**パッケージ化されていない拡張機能を読み込む**」をクリックします。
    - このプロジェクトフォルダ内の `dist` ディレクトリを選択します。

## 使い方

1.  保存したいウェブページを開きます。
2.  ブラウザのツールバーにある Mark Harvest のアイコンをクリックします。
3.  「**Harvest Content**」ボタンをクリックします。
4.  コンテンツがクリップボードにコピーされます！

## 開発用コマンド

- `pnpm dev`: Vite 開発サーバーを起動します。
- `pnpm build`: 本番用ビルドを実行します（`dist/` ディレクトリに出力）。
- `pnpm test`: Vitest でテストを実行します。
